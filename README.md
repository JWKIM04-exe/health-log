# 🏋️ 헬스 기록

여러 명이 각자 루틴을 만들고, 운동별로 세트·무게·횟수를 빠르게 기록하는 웹앱입니다.
설치나 서버 없이 링크만 열면 쓸 수 있고, 폰 홈 화면에 추가하면 앱처럼 동작합니다.

## 쓰는 법
1. 링크 접속 → 이름 입력
2. **루틴** 탭에서 루틴 만들기 (예: `월 - 가슴/삼두`)
3. **운동** 탭에서 루틴 `시작` → 세트마다 무게·횟수 확인하고 ✓ 체크
4. `운동 완료` → **기록**, **성장** 탭에서 확인

### 입력을 빠르게 하는 기능
- 지난번 기록이 자동으로 채워짐 (바뀐 것만 수정)
- `＋ 세트`는 윗 세트를 그대로 복사
- `−` `+` 버튼으로 무게(기본 2.5kg)·횟수 조절
- ✓ 체크하면 휴식 타이머 자동 시작 (기본 90초)
- 이전 최고 무게를 넘기면 🏆 신기록 알림

### 그 밖의 기능
- 운동한 날 달력, 운동별 최고 무게 그래프, 개인 최고 기록(PR) 목록
- 운동별 메모
- 루틴 공유 코드: 친구 루틴을 복사해서 가져오기
- 한 기기에서 여러 사용자 전환
- 백업 파일 내보내기/불러오기 (폰 바꿀 때)

## 폰 홈 화면에 추가
- **아이폰(Safari)**: 공유 버튼 → `홈 화면에 추가`
- **안드로이드(Chrome)**: 메뉴(⋮) → `홈 화면에 추가` 또는 `앱 설치`

## 데이터 저장 방식 (중요)
기록은 **각자 기기의 브라우저(localStorage)** 에 저장됩니다. 서버가 없어서 무료이고 개인정보가 밖으로 나가지 않지만,
- 다른 사람의 기록은 보이지 않습니다 (루틴은 공유 코드로 주고받기)
- 브라우저 데이터를 지우면 기록도 사라지니 **설정 → 백업**을 가끔 해두세요

친구끼리 기록·랭킹을 함께 보려면 나중에 Supabase나 Firebase 같은 서버를 붙이면 됩니다.

## 배포 (GitHub Pages)
저장소 **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`** 저장.
1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다.
